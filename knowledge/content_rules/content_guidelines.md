## 1. Content Type Specifications

### 1.1 Long-Form Articles

| Parameter | Specification |
|-----------|--------------|
| **Minimum word count** | 1,500 words |
| **Target word count** | 2,500–4,000 words |
| **Maximum word count** | 6,000 words |
| **Heading structure** | H1 (title), H2 (sections), H3 (subsections) |
| **Paragraph length** | 2–4 sentences |
| **Paragraph count** | 8–20 paragraphs |
| **Internal links** | Minimum 3 contextual links |
| **CTA** | One clear call-to-action per article |
| **Reading time** | 8–15 minutes |

### 1.2 Social Media Posts

| Platform | Character Limit | Target Length | Format |
|----------|----------------|---------------|--------|
| **X (Twitter)** | 280 chars | 100–250 chars | Single post or thread (3–8 posts) |
| **LinkedIn** | 3,000 chars | 1,300–2,200 chars | Text post with optional image/document |
| **Facebook** | 63,206 chars | 400–1,200 chars | Text + image/video |
| **Reddit** | 40,000 chars (post) | 300–2,000 chars | Post + comments |
| **TikTok** | Caption: 2,200 chars | Caption: 50–150 chars | Video: 15–60 seconds |
| **Instagram** | Caption: 2,200 chars | Caption: 100–250 chars | Image/Reel/Story |

### 1.3 Video Content

| Parameter | Specification |
|-----------|--------------|
| **Short-form (TikTok/Reels/Shorts)** | 15–60 seconds |
| **Medium-form (LinkedIn)** | 60–180 seconds |
| **Long-form (YouTube)** | 3–20 minutes |
| **Hook** | First 3 seconds must capture attention |
| **Caption** | Required; include keywords and hashtags |
| **Aspect ratio** | 9:16 for vertical, 16:9 for horizontal, 1:1 for feed |
| **Resolution** | Minimum 1080p |
| **Format** | MP4, H.264 codec |
| **File size** | Maximum 500MB for upload |

### 1.4 Thread Format (X/Twitter, LinkedIn)

| Parameter | Specification |
|-----------|--------------|
| **Minimum posts** | 3 |
| **Maximum posts** | 10 |
| **Post length** | 100–250 chars each (X), 100–300 chars (LinkedIn) |
| **First post** | Hook + thesis statement |
| **Middle posts** | Supporting evidence, examples, data |
| **Final post** | Conclusion + CTA |
| **Hashtags** | 3–5 per thread total |

## 2. SEO Requirements

### 2.1 Keyword Strategy

| Element | Requirement |
|---------|------------|
| **Primary keyword** | One per article, appears in title, H1, first 100 words, URL |
| **Secondary keywords** | 2–3 per article, distributed naturally throughout |
| **LSI keywords** | 3–5 semantically related terms |
| **Keyword density** | 0.5–1.5% for primary keyword |
| **Long-tail keywords** | Include in subheadings and body paragraphs |

### 2.2 On-Page SEO

| Element | Requirement |
|---------|------------|
| **Title tag** | 50–60 characters, includes primary keyword |
| **Meta description** | 150–160 characters, includes primary keyword and CTA |
| **URL slug** | Short, hyphenated, includes primary keyword |
| **H1** | Contains primary keyword, matches title |
| **H2s** | Include secondary keywords |
| **Image alt text** | Descriptive, includes keywords where relevant |
| **Internal links** | Minimum 3, contextual |
| **External links** | Minimum 2, authoritative sources |
| **Word count** | Minimum 1,500 words (competitive topics: 2,500+) |

### 2.3 Technical SEO

| Element | Requirement |
|---------|------------|
| **Page speed** | Load time under 3 seconds |
| **Mobile responsive** | Yes |
| **Schema markup** | Article, Organization, Person where applicable |
| **Sitemap** | Updated regularly |
| **Robots.txt** | Correctly configured |
| **Canonical URL** | Set for duplicate content |

| Parameter | Specification |
|-----------|--------------|
| **Featured image** | 1200×630px, JPG, under 200KB |
| **Inline images** | 800×600px max, optimized for web |

- Never use watermarked images
- Attribute all third-party images
- Prefer original or AI-generated images where possible
- Use Australian-relevant imagery when targeting Australian audiences

## 4. Hashtag Best Practices

### 4.1 Platform-Specific Hashtag Strategy

| Platform | Hashtag Count | Strategy |
|----------|--------------|----------|
| **X (Twitter)** | 1–3 | Niche, relevant; avoid trending hijacking |
| **LinkedIn** | 3–5 | Industry + niche + branded |
| **Instagram** | 5–15 | Mix of high-volume and niche |
| **TikTok** | 3–7 | Trending + niche + branded |
| **Facebook** | 0–5 | Minimal; organic reach is key |
| **Reddit** | 0 | No hashtags; use subreddit naming instead |
| **YouTube** | 3–5 | In description; searchable terms |

### 4.2 Hashtag Categories

**Branded hashtags (always include):**
- `#ContentsGeneratorWorkforce`
- `#AgentForge`
- `#FairDinkumPublishing`
- `#TrifectaPro`

**General content hashtags (select per post):**
- `#ContentMarketing` `#AIAgents` `#TechAustralian` `#EbookPublishing` `#HorseRacing`
- `#LinkedIn` `#Twitter` `#Reddit` `#TikTok` `#DigitalMarketing`
- `#AIFirst` `#Automation` `#IndieAuthor` `#ContentStrategy` `#AgentWorkforce`

**Niche hashtags (per topic):**
- `#AIGeneratedContent` `#AgentWorkflows` `#EbookPublishingTips` `#GallopsRacing` `#FormFav`

### 4.3 Hashtag Rules

- Never use more than the platform maximum
- Avoid banned or shadowbanned hashtags
- Do not use irrelevant hashtags for reach (hurts engagement)
- Research hashtag popularity before use
- Branded hashtags always lowercase
- General hashtags capitalize first letter of each word (#ContentMarketing not #contentmarketing)
- Update hashtag list quarterly

## 5. Posting Schedules

### 5.1 Platform Posting Frequency

| Platform | Optimal Times (AEST) | Days | Frequency | Content Types |
|----------|---------------------|------|-----------|---------------|
| **LinkedIn** | 8–9am, 12–1pm, 5–6pm | Mon–Fri | 1 post/day | Articles, text posts, documents |
| **X (Twitter)** | 7–8am, 12–1pm, 6–8pm | Daily | 3–5 posts/day | Text, threads, images, links |
| **Reddit** | 6–9pm weekdays, 10am–2pm weekends | Daily | 1–2 posts/day | Posts, comments |
| **TikTok** | 12–2pm, 7–9pm | Tue–Sun | 1–2 videos/day | Short-form video |
| **Facebook** | 1–3pm weekdays, 12–1pm weekends | Mon–Fri | 1 post/day | Text + image/video |
| **YouTube** | 2–4pm (upload), 6–8pm (engagement) | Mon, Thu | 1 video/week | Long-form video |
| **Instagram** | 11am, 7–9pm | Mon–Fri | 1–2 posts/day | Image, Reel, Story |

### 5.2 Content Calendar Principles

- **Monday**: Thought leadership articles (LinkedIn, X)
- **Tuesday**: Platform intelligence insights (Reddit, X)
- **Wednesday**: Video content (TikTok, YouTube)
- **Thursday**: Community engagement (Reddit, LinkedIn comments)
- **Friday**: Behind-the-scenes, process content
- **Saturday**: Entertainment/cultural content (light)
- **Sunday**: Curated content, planning for the week

### 5.3 Timezone Considerations

- All times are Australian Eastern Standard Time (AEST, UTC+10)
- Adjust for daylight saving time (AEDT, UTC+11, Oct–Apr)
- Content published at optimal times regardless of author location
- Schedule posts in advance using the Publishing agent

## 6. Content Approval Workflow

### 6.1 Mandatory Gates

```
Draft Created → QA Check → Fact Check → Human Approval → Publish
```

### 6.2 QA Check Checklist

- [ ] Brand voice compliance (tone, style, personality)
- [ ] Australian English conventions applied
- [ ] Grammar and spelling correct
- [ ] Formatting matches platform specifications
- [ ] Hashtags are appropriate and within limits
- [ ] No prohibited content (profanity, political, etc.)
- [ ] AI disclosure present where required
- [ ] Image/video assets are licensed or AI-generated
- [ ] Internal and external links are correct
- [ ] SEO elements are populated (title, meta, alt text)

### 6.3 Fact Check Checklist

- [ ] All factual claims have sources
- [ ] Statistics are accurate and current
- [ ] Quotes are attributed correctly
- [ ] No fabricated data or claims
- [ ] Third-party information is verified
- [ ] Predictions are labeled with confidence levels
- [ ] AI-generated content is disclosed

### 6.4 Human Approval Checklist

- [ ] Content aligns with current strategy
- [ ] No compliance issues remain
- [ ] Tone matches brand voice
- [ ] CTA is clear and appropriate
- [ ] Platform-specific formatting is correct
- [ ] Timing is optimal for the platform
- [ ] All images/assets are properly attributed

### 6.5 Approval Authority

| Content Type | Required Approval |
|-------------|-------------------|
| Social media post | QA + Fact Check agent |
| Article/blog post | QA + Fact Check + Brett Sjoberg |
| Video script | QA + Fact Check + Brett Sjoberg |
| Campaign-level content | QA + Fact Check + Brett Sjoberg + Marketing review |
| Product announcements | QA + Fact Check + Brett Sjoberg + Legal review |

## 7. Content Quality Standards

### 7.1 The "Would Brett Read This?" Test

Before any content is published, ask:
1. Would I, as Brett, find this valuable?
2. Would I share this with a colleague?
3. Does this sound like something a smart Australian would write?
4. Is there a clear takeaway?
5. Is the quality high enough for the platform?

### 7.2 Quality Metrics

| Metric | Target |
|--------|--------|
| **Readability score** | Grade 8–10 (Flesch-Kincaid) |
| **Sentence length** | Average 15–20 words |
| **Paragraph length** | 2–4 sentences |
| **Active voice ratio** | >80% |
| **Passive voice ratio** | <20% |
| **Jargon frequency** | Defined on first use |
| **AI disclosure** | 100% compliance |
| **Source attribution** | 100% of factual claims |

### 7.3 Common Quality Issues to Avoid

- Filler phrases ("It is important to note that…", "In conclusion…")
- Corporate jargon ("leverage synergies", "circle back", "move the needle")
- Passive constructions ("The data was analysed" → "We analysed the data")
- Hedging language ("might", "could potentially", "possibly") unless uncertainty is genuine
- Exclamation mark overuse
- Vague claims without evidence ("Many people think…" → "According to [source]…")
- Inconsistent tone across a single piece
