## 1. Platform Overview

LinkedIn is the professional network for B2B communication, thought leadership, and career development. It rewards long-form content, authentic professional insights, and consistent engagement.

---

## 2. Professional Tone Requirements

### 2.1 Tone Guidelines

| Element | LinkedIn Requirement |
|---------|---------------------|
| **Tone** | Professional, authoritative, yet approachable |
| **Voice** | Confident, knowledgeable, helpful |
| **Language** | Business English (Australian English conventions apply) |
| **Formality** | Semi-formal — professional but human |
| **Humor** | Light, appropriate, never at others' expense |
| **Opinion** | Well-reasoned, backed by data |
| **Controversy** | Avoid political, religious, and divisive topics |

### 2.2 Tone Examples

✅ **Good LinkedIn tone:**
> "After 6 months of testing our agent workforce, we've found that research before production is the single biggest factor in content quality. Here's what the data shows."

❌ **Bad LinkedIn tone:**
> "OMG this stuff is absolutely game-changing!! Our AI platform is literally revolutionizing everything lol"

### 2.3 LinkedIn-Specific Voice Rules

- More formal than X/Twitter, more human than corporate LinkedIn norms
- Lead with insight, not self-promotion
- Share lessons learned, failures, and honest analysis
- Use data and evidence to support claims
- Reference the brand voice guidelines but adapt slightly for LinkedIn's professional context
- Never use exclamation marks or hype language

## 3. Content Formats

### 3.1 Article vs. Post vs. Document

| Format | Character Limit | Best For | Length | Engagement |
|--------|----------------|----------|--------|------------|
| **Text Post** | 3,000 characters | Quick thoughts, questions, updates | 1–3 paragraphs | Medium |
| **Article** | 100,000 characters | Deep dives, thought leadership | 1,000–5,000 words | High (long-term) |
| **Document (PDF)** | Unlimited | Reports, guides, whitepapers | Variable | Medium |
| **Video** | N/A (uploaded) | Personal, behind-the-scenes | 30 sec–10 min | High |
| **Poll** | Question: 25 chars, Options: 25 chars each | Engagement, opinions | Fixed | High |
| **Carousel** | Per slide: ~1,100 chars | Educational, step-by-step | 5–10 slides | High |

### 3.2 Article Format (Long-Form)

| Element | Requirement |
|---------|------------|
| **Title** | 50–60 characters, includes primary keyword |
| **Introduction** | 1–2 paragraphs, hook the reader |
| **Body** | 1,500–5,000 words, structured with H2/H3 |
| **Conclusion** | Summary + CTA |
| **Cover image** | 1200×627px, JPG/PNG |
| **Author bio** | At end of article |
| **Tags** | 3–5 relevant topics |
| **Publication time** | Tue–Thu, 8–10am AEST |

### 3.3 Post Format (Short-Form)

| Element | Requirement |
|---------|------------|
| **Hook** | First 2 lines must grab attention |
| **Body** | 1,300–2,200 characters optimal |
| **CTA** | Clear call-to-action at the end |
| **Image** | Include for 2x engagement |
| **Tags** | 3–5 relevant topics |
| **Formatting** | Line breaks, bullet points, bold text |
| **Hashtags** | 3–5 per post |

### 3.4 Document Format (PDF)

| Element | Requirement |
|---------|------------|
| **Format** | PDF, under 100MB |
| **Pages** | 5–20 pages optimal |
| **Title** | Descriptive, keyword-rich |
| **Cover** | Professional design |
| **Content** | Actionable, well-researched |
| **Best for** | Guides, reports, case studies, frameworks |
| **Download CTA** | "Download the free PDF" |

## 4. Hashtag Limits

### 4.1 LinkedIn-Specific Hashtag Rules

| Rule | Detail |
|------|--------|
| **Maximum hashtags** | 3–5 per post |
| **Optimal count** | 3 hashtags (best engagement data) |
| **Placement** | At the end of the post |
| **Format** | #Hashtag (CamelCase) |
| **Branded hashtags** | Always include at least 1 |

### 4.2 LinkedIn Hashtag Strategy

| Category | Examples | Count |
|----------|----------|-------|
| **Branded** | #ContentsGeneratorWorkforce, #AgentForge | 1–2 |
| **Industry** | #ContentMarketing, #AIAgents, #TechInnovation | 1–2 |
| **Niche** | #AgentWorkforce, #AIFirst, #IndiePublishing | 1–2 |
| **Total** | | **3–5** |

### 4.3 Hashtag Rules

- Never use more than 5 hashtags
- Only use relevant hashtags — LinkedIn penalizes spam
- Research hashtag popularity before use
- Use CamelCase for readability (#ContentMarketing)
- Place hashtags at the end, not in the body
- Create a branded hashtag and use it consistently

| Day | Best Times | Notes |
|-----|-----------|-------|
| **Tuesday** | 8–9am, 12–1pm | Highest engagement |
| **Wednesday** | 8–9am, 12–1pm | Consistent performance |

| Content Type | Frequency |
|-------------|-----------|
| **Posts** | 3–5 per week |
| **Articles** | 1–2 per week |
| **Documents** | 1 per month |

- 10% promotional (products, announcements)
- 5% curated (sharing others' relevant content)

## 7. LinkedIn-Specific Formatting

### 7.1 Text Formatting Rules

| Element | Format |
|---------|--------|
| **Bold** | **text** for key points |
| **Line breaks** | Use frequently for readability |
| **Bullet points** | Use for lists of 3+ items |
| **Paragraph length** | 2–4 sentences max |
| **First 2 lines** | Hook — visible before "see more" |
| **Hashtags** | At the end, 3–5 |
| **CTA** | Always include |

### 7.2 The "See More" Rule

- LinkedIn truncates posts after 3 lines on mobile
- The first 2 lines MUST be compelling
- Put the most important insight in the first 2 lines
- Use line breaks to create a natural "see more" break
- Don't hide the value — front-load it

### 7.3 Comment Formatting

- Reply to all comments within 24 hours
- Engage in conversations under other posts
- Add value to comments, don't just say "Great post!"
- Use the comment section to elaborate on your post
- Pin a comment to highlight a key insight or CTA
- Use @mentions to tag relevant people

## 9. AI Disclosure on LinkedIn

- All AI-generated or AI-assisted content must be disclosed
- Place disclosure prominently — at the beginning or end of the post
- Use phrases like "AI-assisted," "Created with AI," or "Agent-generated"
- For articles, include disclosure in the author bio or introduction
- For images/videos, label in caption and alt text
- Be transparent about the agent workforce involvement
- LinkedIn is professional — disclosure should be factual, not defensive
