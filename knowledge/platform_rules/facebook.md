## 1. Platform Overview

Facebook remains a significant platform for community building, content distribution, and business presence. However, organic reach has declined significantly, making community engagement and paid strategies more important than ever.

---

## 2. Page vs. Group Posting

### 2.1 Business Page

| Aspect | Guidelines |
|--------|-----------|
| **Purpose** | Official brand presence, content distribution |
| **Content type** | Articles, videos, announcements, events |
| **Posting frequency** | 1 post/day, 3–5x/week |
| **Best times** | 1–3pm weekdays, 12–1pm weekends |
| **Character limit** | 63,206 characters (but keep under 1,200 for engagement) |
| **Image requirement** | Always include an image or video |
| **Link policy** | Links are allowed but may reduce organic reach |

### 2.2 Community Groups

| Aspect | Guidelines |
|--------|-----------|
| **Purpose** | Community engagement, relationship building |
| **Content type** | Discussions, questions, helpful answers |
| **Posting frequency** | 1–2 posts/week per group |
| **Best times** | Evening hours (6–9pm) |
| **Rules** | Follow each group's specific rules |
| **Promotion** | Minimal — focus on adding value |
| **Self-promotion** | Maximum 10% of group posts |

### 2.3 Key Differences

| Feature | Page | Group |
|---------|------|-------|
| **Audience** | Followers + their networks | Group members |
| **Reach** | Limited organically (2–5%) | Can be higher in active groups |
| **Content style** | Official, polished | Conversational, authentic |
| **Links** | Reduced reach | Better engagement in discussions |
| **Promotion** | Accepted | Heavily restricted |
| **Engagement style** | Comments, reactions | Discussions, replies |

## 3. Image Requirements

### 3.1 Image Specifications

| Image Type | Dimensions | Format | File Size | Notes |
|------------|-----------|--------|-----------|-------|
| **Feed image** | 1200×630px | JPG/PNG | <5MB | Recommended |
| **Link preview** | 1200×630px | JPG/PNG | <5MB | Appears when sharing links |
| **Cover photo** | 820×312px | JPG/PNG | <100KB | Profile and page cover |
| **Profile picture** | 170×170px | JPG/PNG | <100KB | Square crop |
| **Story/Reel** | 1080×1920px | MP4/JPG | <500MB | Vertical format |
| **Album cover** | 1200×1200px | JPG/PNG | <5MB | For albums |
| **Event cover** | 1920×1080px | JPG/PNG | <5MB | For events |

### 3.2 Image Best Practices

- Always include an image — posts without images get significantly less reach
- Use high-quality images (minimum 600px wide)
- Text overlays should be minimal and readable
- Brand colors and logo should be present
- Avoid stock photos that look generic
- Use original or AI-generated images where possible
- Mobile optimization: most Facebook users browse on mobile

### 3.3 Image Content Rules

| Content Type | Guidelines |
|-------------|------------|
| **Infographics** | Clear, readable, branded |
| **Quote cards** | Bold text, high contrast |
| **Behind-the-scenes** | Authentic, candid |
| **Comparison images** | Side-by-side, clear labels |
| **Product images** | Clean, well-lit, on-brand |

## 4. Link Policies

### 4.1 Link Impact on Reach

- External links significantly reduce organic reach
- Facebook's algorithm favors content that keeps users on the platform
- Posts with links get approximately 2–6% organic reach vs. 5–15% for photo posts
- Long-form posts without links can still perform well

### 4.2 Link Strategies

| Strategy | Recommendation |
|----------|---------------|
| **Short links** | Use branded short URLs |
| **Link placement** | In comments, not the post body (for reach) |
| **Native content** | Post text content natively, link in comments |
| **Video links** | Upload natively rather than linking to YouTube |
| **Article posts** | Write a compelling intro, link in comments |
| **Link frequency** | Maximum 2–3 per week |

### 4.3 Link Rules

- Never post more than 2 link posts per week
- Always include compelling text when sharing links
- Disclose affiliate links per Facebook policies
- Do not share misinformation or banned content via links
- Use Facebook's native link preview feature for best display
- Ensure linked content complies with all brand rules

## 5. Engagement Strategies

### 5.1 Building Community

| Strategy | Implementation |
|----------|---------------|
| **Ask questions** | Encourage comments and discussion |
| **Polls** | Use Facebook's native poll feature |
| **Behind-the-scenes** | Share process and authenticity |
| **User-generated content** | Feature community members |
| **Respond promptly** | Reply to every comment within 24 hours |
| **Facebook Groups** | Join and participate in relevant groups |
| **Live video** | Host live Q&A sessions or webinars |
| **Shared content** | Share and comment on others' posts |

### 5.2 Engagement Tactics

- End every post with a question or CTA
- Use Facebook reactions (❤️ 😂 😮 😍 😢 😡 👍 👎) strategically
- Respond to every comment — even a simple "Thanks"
- Pin important comments or posts
- Use Facebook Stories for ephemeral, casual content
- Leverage Facebook Events for webinars, launches, or live sessions
- Join and actively participate in 3–5 relevant groups
- Cross-promote with complementary pages (not competitors)

### 5.3 Engagement Don'ts

- Don't buy likes or followers — Facebook detects and penalizes
- Don't use engagement pods or like-for-like schemes
- Don't post the same content as on other platforms verbatim
- Don't over-post — quality over quantity
- Don't ignore negative comments — address them professionally
- Don't use clickbait or misleading content
- Don't spam groups with promotional content

## 6. Video Requirements

### 6.1 Video Specifications

| Parameter | Specification |
|-----------|--------------|
| **Aspect ratio** | 16:9 (horizontal) or 1:1 (square) |
| **Resolution** | Minimum 720p, recommended 1080p |
| **Duration** | Up to 24 hours (but 1–3 minutes optimal) |
| **Format** | MP4, H.264 |
| **File size** | Maximum 4GB |
| **Frame rate** | 30fps |
| **Captions** | Burned-in or auto-generated |
| **Sound** | Optional; 85% watch without sound |

### 6.2 Video Best Practices

- Native uploads perform better than YouTube links
- First 3 seconds must hook the viewer
- Add captions — most users watch without sound
- Use thumbnails that are clear and compelling
- Keep videos under 3 minutes for maximum reach
- Include a CTA at the end
- Facebook Live videos get significantly more reach
- Reels are prioritized by the algorithm

### 6.3 Video Content Types

| Type | Duration | Purpose |
|------|----------|---------|
| **Behind-the-scenes** | 1–3 min | Authenticity, process |
| **Explainer** | 2–5 min | Education, how-to |
| **Interview** | 5–15 min | Expert insights |
| **Live Q&A** | 15–30 min | Community engagement |
| **Reel** | 15–90 sec | Algorithm-optimized |
| **Event recording** | 30+ min | Webinar or event replay |

## 7. Community Guidelines Compliance

### 7.1 Facebook's Community Standards

| Category | Rule |
|----------|------|
| **Hate speech** | Zero tolerance |
| **Harassment** | Not permitted |
| **Violence** | Not permitted |
| **Nudity** | Restricted |
| **Misinformation** | Not permitted |
| **Spam** | Not permitted |
| **False information** | Not permitted |
| **Intellectual property** | Must respect |

### 7.2 Brand Rule Integration

- All brand rules apply to Facebook content (no profanity, no political content, etc.)
- AI disclosure required for AI-generated content
- Affiliate/sponsorship disclosure required per Facebook's ad policies
- Copyright compliance is strictly enforced
- Community standards may be stricter than general brand rules
- Violations can result in page restrictions or removal

### 7.3 Page-Specific Rules

- Always have a page description and "About" section filled out
- Set up page rules visible to visitors
- Use Facebook's scheduling feature for consistent posting
- Review page insights weekly to understand what works
- Enable messaging for community interaction
- Set up automated responses for common questions

---

## 8. AI Disclosure on Facebook

- Disclose AI-generated or AI-assisted content in post text
- Use phrases like "AI-assisted," "Created with AI tools"
- For videos, include on-screen text and verbal disclosure
- For images, label them in the caption
- Be transparent about the agent workforce involvement
- Do not present AI-generated content as purely human-created
