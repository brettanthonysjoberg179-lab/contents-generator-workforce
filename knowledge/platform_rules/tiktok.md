## 1. Platform Overview

TikTok is a short-form video platform driven by the algorithm and user engagement. Success requires understanding the algorithm, creating compelling hooks, and optimizing for watch time and completion rate.

---

## 2. Video Format Requirements

### 2.1 Technical Specifications

| Parameter | Specification |
|-----------|--------------|
| **Aspect ratio** | 9:16 (vertical) |
| **Resolution** | 1080 × 1920 pixels |
| **Duration** | 15–60 seconds (optimal: 15–30 seconds) |
| **File format** | MP4 |
| **File size** | Maximum 287.6 MB |
| **Frame rate** | 30fps (standard), 60fps for smooth motion |
| **Codec** | H.264 |
| **Audio** | AAC, 128kbps minimum |
| **Upload limit** | 10 minutes maximum (verified accounts) |
| **Captions** | Burned-in or auto-generated |

### 2.2 Video Types

| Type | Duration | Purpose |
|------|----------|---------|
| **Quick tip** | 15–30 seconds | Single actionable insight |
| **Explainer** | 30–60 seconds | Step-by-step process or concept |
| **Behind-the-scenes** | 15–45 seconds | Process transparency, authenticity |
| **Trend participation** | 15–60 seconds | Leverage trending sounds/formats |
| **Story** | 30–60 seconds | Narrative arc with hook, middle, end |
| **Comparison** | 30–60 seconds | Before/after, this vs. that |
| **Reaction** | 15–30 seconds | React to content, news, or trends |

## 3. Hook Strategies

The first 3 seconds determine whether someone watches your video or scrolls past.

### 3.1 Hook Types That Work

| Hook Type | Example | Effectiveness |
|-----------|---------|---------------|
| **Pattern interrupt** | "Stop scrolling — this will save you hours" | ★★★★★ |
| **Contrarian** | "Everyone's doing content wrong" | ★★★★ |
| **Question** | "Why does your content never perform?" | ★★★★ |
| **Stat/result** | "This agent system produced 47 articles in one day" | ★★★★ |
| **Curiosity gap** | "The secret to scalable content is not what you think" | ★★★★★ |
| **Visual hook** | Bold text overlay, surprising visual | ★★★★ |
| **Promise** | "By the end of this, you'll understand agent workflows" | ★★★★ |

### 3.2 Hook Rules

- First 3 seconds MUST grab attention
- No slow intros — get straight to the point
- Use text overlay in the first frame (many users watch without sound)
- Avoid "Hey guys, welcome to my channel" — viewers have seen this a thousand times
- Match the hook to the content — don't bait and switch
- Repeat or reinforce the hook at the 50% mark if the video is long

### 3.3 Hook Template

```
[Pattern Interrupt/Question/Contrarian Statement] + [Benefit/Promise] + [Specificity]
```

Examples:
- "Stop wasting hours on content → Here's the 3-agent system that does it for you"
- "Nobody talks about this → Our AI workforce produced 50 articles in a week"
- "You're doing content marketing wrong → And here's the fix"

## 4. Caption Guidelines

### 4.1 Caption Structure

| Element | Position | Requirements |
|---------|----------|-------------|
| **Hook (text)** | First line | Brief, compelling |
| **Body** | Lines 2–3 | Context, value proposition |
| **CTA** | Final line | Like, comment, follow, link |
| **Hashtags** | After CTA | 3–7 relevant tags |
| **Music credit** | If applicable | Artist and song name |

### 4.2 Caption Rules

| Rule | Detail |
|------|--------|
| **Character limit** | 2,200 characters |
| **Optimal length** | 50–150 characters |
| **Hashtag count** | 3–7 per post |
| **Line breaks** | Use for readability |
| **Emojis** | 1–3 maximum |
| **CTA** | Always include one |
| **Hashtag placement** | After the main caption text |

## 5. Music and Copyright

### 5.1 Music Rules

- Use TikTok's native sound library (licensed for platform use)
- Avoid commercial music unless licensed through TikTok's commercial music library
- Original audio is encouraged and algorithmically favored
- If using external music, ensure it has a commercial-use license
- Always credit the artist in the caption

### 5.2 Copyright Compliance

- Do not use copyrighted music without permission
- Do not use movie/TV audio clips without permission
- AI-generated audio is allowed and owned by the workforce
- Voiceovers must be original or licensed
- Fair use is not guaranteed on TikTok — when in doubt, use original content
- TikTok may mute or remove videos with copyrighted audio

## 6. Posting Times and Algorithm

### 6.1 Optimal Posting Times (AEST)

| Day | Best Times | Notes |
|-----|-----------|-------|
| **Monday** | 12–1pm, 7–9pm | Midday catch, evening scroll |
| **Tuesday** | 7–8am, 12–1pm, 7–9pm | Peak engagement |
| **Wednesday** | 12–1pm, 7–9pm | Consistent mid-week |
| **Thursday** | 12–1pm, 7–9pm | High engagement |
| **Friday** | 6–9pm | Weekend prep, evening activity |
| **Saturday** | 10am–12pm, 7–9pm | Weekend browsing |
| **Sunday** | 7–9pm | Sunday scaries, high engagement |

### 6.2 Algorithm Considerations

| Factor | How to Optimize |
|--------|----------------|
| **Watch time** | Keep videos under 30 seconds when possible; front-load value |
| **Completion rate** | Every second counts; don't pad content |
| **Replays** | Create content worth watching twice |
| **Shares** | Include a share-worthy insight or stat |
| **Comments** | End with a question or provocative statement |
| **Saves** | Create "save-worthy" content (tips, lists, how-tos) |
| **For You Page (FYP)** | Use relevant hashtags, trending sounds, and hooks |
| **First hour** | The algorithm tests content in the first 60 minutes |
| **Engagement velocity** | Rapid engagement signals boost distribution |

### 6.3 Algorithm Don'ts

- Don't buy views or followers — TikTok detects and penalizes
- Don't use banned hashtags or sounds
- Don't post duplicate content
- Don't use misleading thumbnails or titles
- Don't engage in engagement pods
- Don't use third-party apps to boost views
- Don't ignore comments in the first hour

## 8. AI Disclosure on TikTok

- All AI-generated or AI-assisted content must be disclosed
- Include disclosure in the caption: "AI-assisted content" or "Made with AI"
- Voiceover disclosure if the video discusses AI-generated results
- On-screen text disclosure if the video shows AI-generated output
- Do not present AI content as purely human-created
- Be transparent about the agent workforce involvement
