## 1. Platform Overview

X is a fast-paced, real-time platform that rewards concise, engaging content. The character limit drives creativity, but quality and authenticity remain paramount.

---

## 2. Character Limits and Formatting

### 2.1 Character Limits

| Content Type | Character Limit |
|-------------|----------------|
| **Standard post** | 280 characters |
| **Premium post** | 25,000 characters |
| **Thread (individual post)** | 280 characters each |
| **Image caption** | 280 characters (in post text) |
| **Poll question** | 25 characters |
| **Poll option** | 25 characters each |

### 2.2 Posting Best Practices

- Keep posts concise and punchy — under 200 characters for best engagement
- Use line breaks for readability in longer posts
- Emojis are acceptable but use them sparingly (1–3 per post)
- One thought per post — don't cram multiple ideas
- Use numbers and statistics when possible (e.g., "23% more engagement")

### 2.3 Thread Formatting

| Element | Specification |
|---------|--------------|
| **Thread length** | 3–8 tweets |
| **First tweet** | Hook + thesis (under 120 chars) |
| **Middle tweets** | Supporting points, each a single idea |
| **Last tweet** | Conclusion + CTA |
| **Character count per tweet** | 100–250 chars |
| **Hashtags per thread** | 3–5 total |
| **Media in threads** | Add images/videos every 2–3 tweets |

### 2.4 Thread Rules

- Always number tweets (1/N, 2/N, etc.)
- The first tweet must be a hook — it determines if people click through
- Each tweet should be self-contained but part of a larger narrative
- End with a clear CTA or question to drive engagement
- Don't use threads just to share links — threads are for storytelling

## 3. Hashtag Strategy

### 3.1 X-Specific Hashtags

| Category | Examples | Count |
|----------|----------|-------|
| **Branded** | #ContentsGeneratorWorkforce, #AgentForge, #TrifectaPro | Always include |
| **Content** | #ContentMarketing, #AIAgents, #TechAustralian | 1–2 per post |
| **Platform** | #Twitter, #SocialMedia, #LinkedIn | 0–1 per post |
| **Trending** | Relevant trending topics only | 0–1 per post |
| **Total per post** | | **Maximum 3–5** |

### 3.2 Hashtag Rules

- Never use more than 5 hashtags on X
- Hashtags should be relevant to the post content
- Check if a hashtag is trending for the right reasons
- Avoid banned or shadowbanned hashtags
- Use CamelCase for multi-word hashtags (#ContentMarketing not #contentmarketing)
- Don't put hashtags in the middle of sentences
- Place hashtags at the end of the post or in the first comment

## 4. Content Types and Requirements

### 4.1 Text Posts

| Type | Purpose | Length | Frequency |
|------|---------|--------|-----------|
| **Quick take** | Share an insight | 50–120 chars | Daily |
| **Opinion** | Share a perspective | 120–250 chars | 2–3x/week |
| **Question** | Drive engagement | 50–150 chars | 2–3x/week |
| **Announcement** | Product/news updates | 150–280 chars | As needed |
| **Thread** | Deep dive on a topic | 3–8 tweets | 1–2x/week |

### 4.2 Image Posts

| Parameter | Specification |
|-----------|--------------|
| **Aspect ratio** | 16:9 or 1:1 |
| **Resolution** | Minimum 1080px wide |
| **Format** | JPG or PNG |
| **File size** | Under 5MB |
| **Alt text** | Required for accessibility |
| **Text overlay** | Keep minimal, readable |
| **Branding** | Consistent visual identity |

### 4.3 Video Content

| Parameter | Specification |
|-----------|--------------|
| **Duration** | Under 2 minutes 20 seconds |
| **Aspect ratio** | 16:9 or 1:1 |
| **Resolution** | 1080p |
| **Format** | MP4 |
| **File size** | Under 512MB |
| **Captions** | Required (80% of users watch without sound) |
| **First 3 seconds** | Must hook the viewer |

### 4.4 Link Posts

- Always include custom text — never just a bare link
- The tweet text should tease the article's value
- Post links during peak engagement times (8–10am, 12–1pm, 6–8pm AEST)
- Never post more than 2 link tweets in a single thread
- Accompany links with an image when possible

## 5. Engagement Tactics

### 5.1 Daily Engagement Routine

| Time | Activity |
|------|----------|
| **Morning (7–9am)** | Post morning thoughts, engage with replies |
| **Midday (12–1pm)** | Post midday content, reply to mentions |
| **Afternoon (3–5pm)** | Engage with others' content, reply to threads |
| **Evening (6–8pm)** | Post evening content, engage with community |

### 5.2 Engagement Rules

- Reply to every comment on your posts within 2 hours
- Engage with 10+ other users' content daily
- Quote tweet thoughtfully — add value, don't just agree
- Retweet only content you genuinely find valuable
- Use replies to start conversations, not just say "thanks"
- Tag relevant accounts when appropriate
- Use polls to drive engagement

### 5.3 Engagement Don'ts

- Don't engage in arguments or flame wars
- Don't reply with single emojis to build engagement
- Don't use engagement pods or follow/unfollow schemes
- Don't mass-reply to strangers with promotional content
- Don't use automated DM campaigns for promotion
- Don't buy followers or engagement
- Don't post identical content repeatedly

## 6. Posting Frequency and Schedule

### 6.1 Optimal Posting Times (AEST)

| Day | Best Times | Notes |
|-----|-----------|-------|
| **Monday** | 8–9am, 12–1pm | Thought leadership posts |
| **Tuesday** | 7–8am, 6–8pm | Engagement posts, threads |
| **Wednesday** | 12–1pm | Mid-week content |
| **Thursday** | 8–9am, 5–6pm | Behind-the-scenes, process |
| **Friday** | 12–1pm | Lighter content, weekend prep |
| **Saturday** | 10am–12pm | Lighter engagement |
| **Sunday** | 8–10pm | Reflection posts |

### 6.2 Frequency Guidelines

| Content Type | Frequency |
|-------------|-----------|
| **Quick takes** | 2–5 per day |
| **Opinion posts** | 2–3 per day |
| **Threads** | 1–2 per week |
| **Image posts** | 1–3 per day |
| **Video posts** | 1–2 per week |
| **Polls** | 1–2 per week |
| **Total posts** | 5–15 per day |

### 6.3 Content Mix Ratio

- 60% value (insights, education, analysis)
- 20% engagement (questions, polls, discussions)
- 10% promotional (products, announcements)
- 10% personal (behind-the-scenes, personality)

## 7. AI Disclosure on X

- All AI-generated or AI-assisted content must be disclosed
- Use phrases like "AI-assisted," "Created with AI," or "AI-generated content"
- Place disclosure prominently — not hidden in thread
- Threads about AI should include a disclosure in the first tweet
- Do not use AI to impersonate or generate misleading content
- When sharing AI-generated images, label them clearly

## 8. Visual Content Requirements

### 8.1 Image Guidelines

| Element | Specification |
|---------|--------------|
| **Brand colors** | Consistent with brand palette |
| **Typography** | Clean, readable fonts |
| **Logo** | Subtle branding on images |
| **Quote cards** | Bold text on colored backgrounds |
| **Data visualization** | Simple charts, clear labels |
| **Screenshots** | Highlight relevant portions |
| **Memes** | Only when culturally appropriate and on-brand |

### 8.2 Video Thumbnails

- Custom thumbnails for every video post
- 1200×675px minimum
- Clear text overlay (3–5 words max)
- High contrast, readable
- Face thumbnails perform better than text-only

### 9.1 Platform Rules

- Follow X's rules of conduct
- No hate speech, harassment, or manipulation
- No misinformation or misleading content
- No spam or manipulation of algorithms
- No impersonation of other users or brands
- Comply with X's advertising policies

### 9.2 Content Warnings

- X provides CW functionality — use it appropriately

- Enable two-factor authentication
- Review connected apps periodically
- Use strong, unique passwords
- Monitor for impersonation accounts
- Report suspicious activity promptly
